Part 1 Project Foundation & Objectives
▼

CHAKRAVYUH is an AI-powered Red Team simulation platform designed to coordinate controlled cybersecurity experiments through a centralized AI Planner.

The platform initially supports four simulation categories: Authentication attack simulation, Service-load simulation, Phishing-awareness simulation, and Wireless-security simulation.

Exclusions: Attacks against public systems, unrestricted network flooding (DDoS), real credential theft, unauthorized radio disruption, and autonomous execution of arbitrary OS commands are strictly out of scope.
Part 2 Laboratory Environment & Network Isolation
▼

The initial environment consists of a Kali Linux VM (Red Team simulation), Windows VM (Authorized target), and Development Machine (Streamlit, Python, SQLite).

Network Configuration: Use an isolated host-only virtual network. No public targets, no unintended bridge to external networks, explicitly configured target IP addresses, and only approved ports and services.

Part 18 15 Technical Reviewer Questions & Defense Answers
▼
Q1. Why use AI instead of fixed Python scripts?

AI dynamically interprets objectives, recommends tailored profiles from catalogs, and evaluates telemetry. Python enforces deterministic safety and execution control.

Q3. Can the AI directly execute commands?

No. The AI produces structured JSON proposals. The Safety Gateway and Python execution engine independently validate and control what can run.

Q4. How do you prevent unauthorized execution?

Through target allowlisting, scenario permissions, parameter validation, resource limits, and adapter-level safeguards.
