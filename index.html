Part 1-2 Project Foundation & Laboratory Environment
▼

CHAKRAVYUH is an AI-powered Red Team simulation platform designed to coordinate controlled cybersecurity experiments through a centralized AI Planner.

Core Design Principle: AI plans. Python validates. The Safety Gateway authorizes. Adapters execute. The Observation Engine measures.

Exclusions: Public network targets, unconstrained DDoS, actual password harvesting, physical radio interference, and autonomous shell command execution are explicitly prohibited.

Part 18 15 Technical Reviewer Questions & Defense Arguments
▼
Q1. Why use AI instead of fixed Python scripts?

AI interprets objectives, recommends approved scenario categories, and evaluates resulting observations. Python remains responsible for deterministic authorization and safe execution.

Q3. Can the AI directly execute commands?

No. The AI produces structured JSON requests. The Safety Gateway and execution system control what can actually run.

Q4. How do you prevent unauthorized execution?

Target allowlisting, scenario permissions, parameter bounds, resource limits, and cooperative kill-switch cancellation tokens.
